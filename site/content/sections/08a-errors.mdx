## Errors

An error in a query shows at its line and column, in your editor as you type and in `tsc`. TypeScript's own language server reports it, inside the `.sql` file itself, so Reylo needs no editor plugin. Your editor needs only:

- **TypeScript 7.1** installed in your project ([Install](#install))
- **The TypeScript 7 extension**, pointed at your project's TypeScript ([Editor](#editors)). Zed shows an error inside a `.sql` file only in `tsc`.

Your database checks each query, so a misspelled column is the database's own error:

```sql tab="get_user.sql" dialect="all" errors
select id, nmae, email
from users
where id = :id::int
```

Two columns of one name are an error, since each row is an object and keeps only the last:

```sql tab="post_ids.sql" dialect="all" errors
select u.id, p.id, p.title
from users u
join posts p on p.user_id = u.id
```

Sorting or grouping by a parameter is an error, since a parameter is a value and every row would sort the same. To let the caller choose the order, see [Dynamic sorting](#dynamic-sorting):

```sql tab="list_users.sql" dialect="all" errors
select id, name
from users
order by :sort::text
```

A [parameter whose type cannot be inferred](#a-parameter-nothing-types) is Reylo's error too, which says to cast it. When a query changes, its types change with it, and code that reads a column the query no longer selects is an error:

```ts twoslash tab="main.ts"
// @errors: 2339
import listPosts from "./list_posts.sql";

const posts = await listPosts.run(db);
for (const post of posts) console.log(post.body);
```

```sql tab="list_posts.sql" dialect="all"
select id, title
from posts
order by id
```

A wrong argument is an error where you call `.run()`:

```ts twoslash
// @errors: 2322
import getUser from "./get_user.sql";

const user = await getUser.run(db, { id: "1" });
```

The type check reports the same errors:

```ansi title="Terminal"
$ tsc --noEmit --runExternalCode
[96mget_user.sql[0m:[93m1[0m:[93m12[0m - [91merror[0m[90m reylo6: [0mcolumn "nmae" does not exist (42703)

[7m1[0m select id, nmae, email
[7m [0m [91m           ~~~~[0m

Found 1 error in get_user.sql[90m:1[0m
```

While a `.sql` file has an error, `tsc` holds back the TypeScript errors, so fix the SQL first.
