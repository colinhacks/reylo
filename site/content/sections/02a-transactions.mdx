## Transactions

A transaction is a client: take one from your driver, and pass it to `.run()`.

Await each query in turn, since a connection runs one statement at a time: a `pg` client handed several at once by `Promise.all` warns, and `pg` 9 will refuse them. On Postgres, an error aborts the transaction, so every later statement in it fails until it rolls back ([Database errors](/postgres#database-errors)).

### Postgres [#postgres-transactions]

```ts twoslash tab="pg" dialect="postgres" tab-group="postgres-driver"
import pg from "pg";
import getUser from "./get_user.sql";
const db = new pg.Pool({ connectionString: process.env.DATABASE_URL });
// ---cut---
const client = await db.connect();
try {
  await client.query("begin");
  await getUser.run(client, { id: 1 });
  await client.query("commit");
} catch (error) {
  await client.query("rollback");
  throw error;
} finally {
  client.release();
}
```

### MySQL [#mysql-transactions]

```ts twoslash tab="mysql2" dialect="mysql" tab-group="mysql-driver"
import mysql from "mysql2/promise";
import getUser from "./get_user.sql";
const db = mysql.createPool(process.env.DATABASE_URL);
// ---cut---
const conn = await db.getConnection();
try {
  await conn.beginTransaction();
  await getUser.run(conn, { id: 1 });
  await conn.commit();
} catch (error) {
  await conn.rollback();
  throw error;
} finally {
  conn.release();
}
```

### SQLite [#sqlite-transactions]

```ts twoslash tab="better-sqlite3" dialect="sqlite" tab-group="sqlite-driver"
import Database from "better-sqlite3";
import getUser from "./get_user.sql";
const db = new Database("app.db");
// ---cut---
// the function must not await, so it runs .runSync()
db.transaction(() => getUser.runSync(db, { id: 1 }))();
```

### DuckDB [#duckdb-transactions]

DuckDB's transaction is on the connection itself:

```ts tab="@duckdb/node-api"
await db.run("begin");
try {
  await getUser.run(db, { id: 1 });
  await db.run("commit");
} catch (error) {
  await db.run("rollback");
  throw error;
}
```
