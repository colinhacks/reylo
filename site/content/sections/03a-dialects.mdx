## Dialects

Each database Reylo supports has a page of its own, with every rule and edge case.

### Postgres

Postgres 14 to 18, through `pg`, postgres.js, `Bun.sql`, PGlite, Neon, `pg-promise`, Slonik, `@vercel/postgres` or Drizzle.

[Postgres reference →](/postgres)

### MySQL

MySQL 8.0.22 or later, through `mysql2`, `mariadb`, PlanetScale, `Bun.sql` or Drizzle.

[MySQL reference →](/mysql)

### SQLite

SQLite, through `better-sqlite3`, `node:sqlite`, `bun:sqlite`, `Bun.sql`, libSQL, Turso, Cloudflare D1, Durable Objects, `sqlite3`, `sqlite` or Drizzle.

[SQLite reference →](/sqlite)

### DuckDB

DuckDB 2.0, through `@duckdb/node-api`.

[DuckDB reference →](/duckdb)
