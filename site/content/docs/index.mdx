Reylo is an engine that infers type information from SQL queries.

It has your live database prepare each query, without running it, and reads the catalog. Reylo is the perfect option for the agent era:

<div className="dk-features">

- 💪 **The full power of SQL** — any syntax, function or operator your database supports
- 🌵 **DRY** — no redundant hand-written types
- 🎯 **Checked against your database** — a misspelled column is a compile error
- 🤖 **Agent-friendly** — DRY code is more maintainable for agents
- 🧩 **Postgres, MySQL and SQLite** — and DuckDB (preview) in TypeScript; Neon, PlanetScale, Cloudflare D1, Turso and more
- 🔌 **Your own driver** — `pg`, postgres.js, `mysql2`, `better-sqlite3` and [more](/typescript#run) in TypeScript, sqlx in Rust

</div>

Reylo comes in three pieces: the engine and its CLI, a content mapper for TypeScript, and a macro for Rust.

### The CLI

The engine is one native program, the `reylo` command, which prints what it infers for each statement, such as how many rows it returns and each column's type:

<Analyzed file="get_author.sql" jq=".result">

```sql schema
create table users (
  id serial primary key,
  name text not null
);
create table posts (
  id serial primary key,
  user_id integer not null references users (id)
);
```

```sql
select u.id, u.name, count(p.id)::int as post_count
from users u
left join posts p on p.user_id = u.id
where u.id = :id::int
group by u.id
```

</Analyzed>

It also writes and runs your migrations ([Migrations](/migrations)). Every command is on the [CLI](/cli) page.

### TypeScript

A TypeScript 7.1 content mapper types each `.sql` file you import, in your editor and in `tsc`.

```sql title="get_author.sql"
select u.id, u.name, count(p.id)::int as post_count
from users u
left join posts p on p.user_id = u.id
where u.id = :id::int
group by u.id
```

```ts twoslash title="main.ts" dialect="postgres"
// @noErrors
import postgres from "postgres";
import getAuthor from "./get_author.sql";

const db = postgres(process.env.DATABASE_URL);
const author = await getAuthor.run(db, { id: 1 });

author?.
//      ^|
```

To set it up, see [Usage with TypeScript](/typescript).

### Rust

An attribute macro types each statement as your crate compiles, and runs it on sqlx:

<Completion items="id: i32, name: String, post_count: i32" at="7">

```rust title="main.rs"
#[reylo::query("
    select u.id, u.name, count(p.id)::int as post_count
    from users u
    left join posts p on p.user_id = u.id
    where u.id = :id::int
    group by u.id
")]
pub mod get_author {}

let author = get_author::Query { id: 1 }.run(&pool).await?.expect("author 1");
author.
```

</Completion>

To set it up, see [Usage with Rust](/rust).
