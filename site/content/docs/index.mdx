Reylo is an engine that infers type information from SQL queries.

For a query, Reylo infers what goes in and what comes out:

<InferenceCard>

```sql file="get_user.sql" dialect="all"
select id, name, email from users where id = :id::int
```

</InferenceCard>

In this example:

- The parameter `:id` is cast to `int`, so the query takes a number
- The column `id` is the primary key, so the query returns one row at most, or `null`
- The column `email` isn't `NOT NULL`, so its value can be `null`

Reylo reads all of this from your live database, which checks the query without running it. Reylo is the perfect option for the agent era:

<div className="dk-features">

- 💪 **The full power of SQL** — any syntax, function or operator your database supports
- 🌵 **DRY** — no redundant hand-written types
- 🎯 **Checked against your database** — a misspelled column is a compile error
- 🤖 **Agent-friendly** — DRY code is more maintainable for agents
- 🧩 **Postgres, MySQL and SQLite** — Neon, PlanetScale, Cloudflare D1, Turso and more
- 🔌 **Your own driver** — `pg`, postgres.js, `mysql2`, `better-sqlite3` and [more](/typescript#run) in TypeScript<Rust>, sqlx in Rust</Rust>

</div>

The same engine is behind <Rust>three</Rust><NoRust>two</NoRust> ways to use it.

### TypeScript

A content mapper, new in TypeScript 7.1, types each `.sql` file you import, so your editor knows the columns of every row:

```sql title="get_author.sql"
select u.id, u.name, count(p.id)::int as post_count
from users u
left join posts p on p.user_id = u.id
where u.id = :id::int
group by u.id
```

```ts twoslash title="main.ts" dialect="postgres"
// @noErrors
import postgres from "postgres";
import getAuthor from "./get_author.sql";

const db = postgres(process.env.DATABASE_URL);
const author = await getAuthor.run(db, { id: 1 });

author?.
//      ^|
```

### Rust

An attribute macro types each statement as your crate compiles, and runs it on sqlx:

<Completion items="id: i32, name: String, post_count: i32" at="7">

```rust title="main.rs"
#[reylo::query("
    select u.id, u.name, count(p.id)::int as post_count
    from users u
    left join posts p on p.user_id = u.id
    where u.id = :id::int
    group by u.id
")]
pub mod get_author {}

let author = get_author::Query { id: 1 }.run(&pool).await?.expect("author 1");
author.
```

</Completion>
