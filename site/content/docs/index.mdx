Reylo is a type inference engine for SQL. It lets you import SQL queries into your TypeScript files with full type information.

If you have a query like this:

<SchemaQuery>

```sql file="schema.sql" tab="Postgres" tab-group="dialect"
create extension if not exists pg_jsonschema;

create type user_role as enum ('admin', 'member');

create table users (
  id serial primary key,                     -- at most one row per id
  name text not null,                        -- name: string
  email text unique,                         -- email: string | null
  role user_role not null default 'member',  -- role: "admin" | "member"
  tags text[] not null default '{}',         -- tags: (string | null)[]
  created_at timestamptz                     -- created_at: string
    not null default now()
);

create table posts (
  id serial primary key,
  user_id integer not null references users (id),
  title text not null,
  body text,
  published_at timestamptz
);

create table events (
  id serial primary key,
  kind text not null
    check (kind in ('click', 'key')),        -- kind: "click" | "key"
  payload jsonb not null                     -- payload: what the schema admits
    check (jsonb_matches_schema('{
      "type": "object",
      "properties": {
        "x": { "type": "integer" },
        "y": { "type": "integer" },
        "code": { "type": "string" }
      }
    }', payload))
);
```

```sql file="schema.sql" tab="MySQL" tab-group="dialect"
create table users (
  id int auto_increment primary key,          -- at most one row per id
  name text not null,                         -- name: string

    not null default 'member',

      "type": "object",

        "x": { "type": "integer" },
```

```sql title="get_author.sql"
select u.id, u.name, count(p.id)::int as post_count
from users u
left join posts p on p.user_id = u.id
where u.id = :id::int
group by u.id
```

</SchemaQuery>

You can import it like this. Hover over `author` to see the inferred type!

```ts twoslash title="main.ts" dialect="postgres"
// @noErrors
import postgres from "postgres";
import getAuthor from "./get_author.sql";

const db = postgres(process.env.DATABASE_URL);
const author = await getAuthor.run(db, { id: 1 });

author?.
//      ^|
```

Reylo relies on the Content Mapper API (introduced in TypeScript 7.1) to let you directly import `.sql` files into TypeScript.

Reylo infers type information about both the parameters and the return types. Throughout the docs, you will see "inference cards" like this where you can quickly see both a query and its inferred type information.

<InferenceCard>

```sql file="get_user.sql" dialect="all"
select id, name, email from users where id = :id::int
```

</InferenceCard>

Reylo gets type information about a query by sending it to a *live dev database* and getting back the database's own type descriptors. It then maps these to TypeScript types. Reylo is the perfect option for the agent era:

<div className="dk-features">

- 💪 **The full power of SQL** — any syntax, function or operator your database supports
- 🌵 **DRY** — no redundant hand-written types

### Rust

An attribute macro types each statement as your crate compiles, and runs it on sqlx:

<Completion items="id: i32, name: String, post_count: i32" at="7">

```rust title="main.rs"
#[reylo::query("
    select u.id, u.name, count(p.id)::int as post_count
    from users u
    left join posts p on p.user_id = u.id
    where u.id = :id::int
    group by u.id
")]
pub mod get_author {}

let author = get_author::Query { id: 1 }.run(&pool).await?.expect("author 1");
author.
```

</Completion>
