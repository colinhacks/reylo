<p className="dk-subheader">How Reylo compares with other tools that type SQL</p>

Reylo isn't the first tool to type SQL: [sqlc](https://sqlc.dev), [sqlx](https://github.com/transact-rs/sqlx) and [PgTyped](https://pgtyped.dev) have typed queries for years, and [Prisma TypedSQL](https://www.prisma.io/docs/orm/prisma-client/using-raw-sql/typedsql), [SafeQL](https://safeql.dev), [TypeSQL](https://github.com/wsporto/typesql) and [Postgres Typed SQL](https://github.com/fli/postgres-typed-sql) do it too. Hover a cross or half circle to see why, or a row's name to see what it asks.
