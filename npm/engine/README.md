# @reylosql/engine-{platform}

The `reylo` binary for {name}: Reylo's analysis engine, which the npm package [`reylo`](https://www.npmjs.com/package/reylo) runs to type `.sql` files from the database itself.

Install [`reylo`](https://www.npmjs.com/package/reylo), not this package. `reylo` lists every platform's package as an optional dependency at its own version, and the package manager installs the one whose `os`, `cpu` and `libc` match the machine. A project never names this package itself.

Docs: [reylo.dev](https://reylo.dev).
